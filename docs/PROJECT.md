# Family VPN

## Цель проекта

Создать личную self-hosted VPN-платформу для семьи, которая:

- работает на iPhone, iPad, macOS, Windows, Android и Android TV;
- легко разворачивается на новом VPS;
- автоматически создаёт резервные копии;
- быстро восстанавливается после сбоев;
- не зависит от коммерческих VPN-сервисов;
- остаётся простой в сопровождении.

---

## MVP

Первая версия должна уметь:

- поднять WireGuard на VPS;
- подключать новые устройства;
- управлять устройствами через веб-интерфейс;
- автоматически делать резервные копии;
- контролировать состояние сервера.

---

## Принципы проекта

- Infrastructure as Code.
- Минимум ручных действий.
- Один VPS — одна ответственность.
- Все изменения фиксируются в Git.
- Простота важнее количества функций.

---

## Что НЕ входит в MVP

- Собственное VPN-приложение.
- Собственный VPN-протокол.
- Собственная веб-панель вместо существующих решений.
- Поддержка нескольких VPS.
- Высокая доступность (HA).

---

## Будущее

После успешного MVP проект может быть расширен:

- поддержка нескольких серверов;
- централизованное управление;
- собственная панель управления;
- автоматическое восстановление инфраструктуры;
- управление несколькими локациями.
